# 🎧 Roastify

**Your Spotify taste deserves to be roasted.**

Roastify analyzes your Spotify listening taste and delivers hilarious roasts based on your music preferences.

## ✨ Features

- 🎵 Spotify integration
- 🔥 Personalized music taste roasts
- 🎨 Dark-themed UI
- ⚡ Fast and responsive interface

## 🛠️ Built With

- Next.js
- React
- TypeScript
- CSS

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/bug-hunter303/Roastify.git
```

Navigate into the project:

```bash
cd Roastify
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
